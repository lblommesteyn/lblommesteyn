## USB2517 hub configuration (over SMBus, HUB_SDA/HUB_SCL)

| consumer | physical port | D+/D- swapped |
|---|---|---|
| CH1 | DN3 | no |
| CH2 | DN4 | no |
| CH3 | DN6 | no |
| CH4 | DN7 | no |
| MCU | DN5 | yes |
| upstream (J3) | UP | no |

- PORT_SWAP (0xFA) = 0x20  (bit 0 = upstream, bit n = DNn)
- Set port-mapping mode (CFG3 bit 3) and program PORT_MAP 0xFB-0xFE so the logical port numbers match the original DN1-DN4 = CH1-CH4, DN7 = MCU.
